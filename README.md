# Tri-Language Notepad Project

A comprehensive notepad application implemented in **Go**, **Rust**, and **C** to demonstrate mastery of modern software development practices, language paradigms, and professional coding standards.

> **Project Goal**: Build three production-quality notepad implementations while learning enterprise-level development practices, code review processes, and best practices across different programming languages.

## 🎯 Quick Start

### Prerequisites
- Go 1.21+
- Rust 1.70+
- C compiler (GCC/Clang) + CMake
- Git
- Node.js 18+ (for pre-commit hooks)

## 📦 Project Structure

| Directory | Purpose |
|-----------|---------|
| **go/** | Go implementation with goroutines |
| **rust/** | Rust implementation with memory safety |
| **c/** | C implementation for performance |
| **docs/** | Architecture and guides |

## 🎯 Features (MVP)

- ✨ Create, open, read, write, delete notes
- 📝 Text editing with undo/redo
- 🔍 Find and replace functionality
- 📊 Statistics (word count, character count, line count)
- 💾 Auto-save functionality
