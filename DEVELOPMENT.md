# Development Guide

This guide explains how to set up your development environment and the workflow for contributing to this project.

## 📋 Prerequisites

### All Platforms
- **Git**: https://git-scm.com/
- **Node.js 18+**: https://nodejs.org/ (for pre-commit)
- **VS Code**: https://code.visualstudio.com/

### Go Development
- **Go 1.21+**: https://golang.org/doc/install

### Rust Development
- **Rust 1.70+**: https://rustup.rs/

### C Development
- **CMake 3.10+**: https://cmake.org/
- **C Compiler**: GCC or Clang
